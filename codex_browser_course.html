START WITH TWO CONNECTIONS

學會兩種看影片的方式

本教材整理兩條瀏覽器操作流程：使用 Codex 內建瀏覽器，或連接目前已登入的 Chrome。先確認使用哪個瀏覽器工作階段，再核對課程頁面和影片狀態；不同網站的播放器與字幕功能可能不同。

學習目標

能選擇合適的瀏覽器方式、確認 Codex 看得到正確課程，並用明確指令要求檢查或操作影片。

帳號條件

依本次需求使用私人 Gmail。請在選定的瀏覽器由本人登入；密碼與驗證碼只輸入在登入頁，不貼到聊天。

完整理解影片仍以實際觀看或可取得的字幕、逐字稿為準。只看見播放器截圖時，應說明目前看見的畫面，不要宣稱已看完整部影片。
CHOOSE YOUR BROWSER

兩種方法：內建瀏覽器與目前 Chrome MCP

兩種方式都先由你登入，再請 Codex 確認頁面。內建瀏覽器通常使用自己的工作階段；Chrome DevTools MCP 可連接目前開著的 Chrome 分頁。選一種開始，確認可讀取課程後再要求操作。

方法一｜Codex 內建瀏覽器
  1. 在 Codex 內建瀏覽器開啟課程網址。
  2. 若需要私人 Gmail 登入，在這個瀏覽器視窗自行登入；不要假設它會沿用一般 Chrome 的登入狀態。
  3. 請 Codex 回報頁面標題、課程單元、目前播放狀態，以及可取得的字幕或文字。
  4. 需要播放、暫停或跳到特定時間時，明確說出動作，並請 Codex 確認畫面或時間是否改變。
方法二｜已登入 Chrome＋Chrome DevTools MCP
  1. 在一般 Chrome 親自登入私人 Gmail，並開啟課程播放器。
  2. 若 MCP 尚未連上 Chrome，前往 chrome://inspect/#remote-debugging 檢查遠端偵錯設定；依 Chrome 提示核對並授權可信任的連線。
  3. 請 Codex 列出可用分頁、選取課程頁，再讀取頁面文字、截圖或影片播放時間。
  4. 需要控制影片時，指定播放、暫停或時間點；完成後再核對播放狀態。
連線安全：遠端偵錯會讓連接的程式控制瀏覽器，也可能讀取 Cookie 和網站資料。只使用可信任的 MCP 連線。這次檢查時遠端偵錯已啟用，顯示 127.0.0.1:9222；目前這個 MCP 方式不需要另外安裝 Chrome 外掛。
01

環境準備

先選擇要使用的瀏覽器工作階段。

  1. 內建瀏覽器：在 Codex 的內建瀏覽器開啟研習網址；登入狀態可能和一般 Chrome 不同。
  2. 目前 Chrome＋MCP：在 Chrome 開啟課程頁。若尚未允許遠端偵錯，前往 chrome://inspect/#remote-debugging 依畫面設定；已有連線時不必重複設定。
  3. Chrome 擴充功能是另一種連線方式，和 Chrome DevTools MCP 分開。單裝一般外掛不會自動提供 MCP；需要時先確認外掛和橋接程式的來源及權限。
貼給 Codex 的指令

請先檢查目前可用的瀏覽器連線方式，分別說明你是否看得到內建瀏覽器或我開啟的 Chrome 課程分頁。先不要登入、播放或改變影片位置。

02

確認課程頁面

先讀取狀態，再進入播放操作。

  1. 在選定的瀏覽器開啟課程平台與影片頁。
  2. 請 Codex 回報網站、課程名稱、章節名稱、播放時間和是否找到字幕或逐字稿。
  3. 核對回報的頁面和課程是否正確；這一步先不要報名、提交資料或切換單元。
貼給 Codex 的指令

請查看目前開啟的研習頁，回報平台、課程、章節、播放時間與可取得的字幕或文字。先只讀取，不要操作影片或提交資料。

03

登入接力

私人帳號由你在瀏覽器登入。

  1. 本次流程需使用私人 Gmail 帳號。若登入頁要求 Google 或個人帳號，請在你選定的瀏覽器本人輸入憑證並完成驗證。
  2. 不要把密碼、驗證碼或復原碼貼到對話；只需告訴 Codex「我已登入」，再指出希望查看的課程頁。
  3. 登入後確認課程名稱與單元清單。若 Codex 看不到新開的分頁，重新指定正確頁面或使用另一種瀏覽器方式。
貼給 Codex 的指令

我已在【內建瀏覽器／Chrome】完成私人 Gmail 登入並開啟課程。請確認頁面和單元清單，先不要切到測驗或提交資料。

04

確認影片開始播放

用時間、字幕或畫面變化確認實際狀態。

  1. 開啟目標單元並等待播放器載入。不要只因為按鈕已點擊，就判定影片開始播放。
  2. 請 Codex 檢查播放器時間、畫面或字幕是否前進；如果頁面要求本人按播放，請依瀏覽器提示自行操作。
  3. 若找不到字幕或影片資訊，請 Codex 說明目前能看到的內容和限制，不要把截圖當作整段影片逐字稿。
貼給 Codex 的指令

請確認第一單元是否真的在播放，回報可見的播放時間、字幕狀態和目前畫面。先不要改變播放速度或跳轉時間；若需要我親自點播放，請告訴我。

05

觀看、操作與章節切換

由你觀看理解，Codex 按指示協助操作。

  1. 由學員實際觀看課程。可請 Codex 暫停、繼續或說明當前可取得的教材、字幕與畫面。
  2. 需要跳到指定時間或切換章節時，說清楚目標，並要求 Codex 回報執行後的播放時間或新章節名稱。
  3. 單元結束後先確認播放器確實到達結尾，再切下一段。若沒有持續執行中的任務，Codex 不會因對話結束而自動在背景監看。
貼給 Codex 的指令

請暫停目前影片並確認時間停止。等我說繼續後再播放；若我要求跳轉或切換單元，先確認目標，完成後回報新的時間和章節。

06

測驗、紀錄與證書

依平台的實際結果完成驗收。

  1. 遇到計入完課資格的測驗，由學員理解題目並作答。Codex 可解釋教材觀念；不要把代考當成操作流程。
  2. 問卷依學員的實際體驗填寫。離開播放器時，優先使用平台的正式離開按鈕，再查看學習紀錄。
  3. 平台確認符合資格且提供證書後，再請 Codex 協助下載並回報實際檔名與位置。不要直接改寫時數或完成狀態。
貼給 Codex 的指令

請查看平台實際顯示的完課條件與學習紀錄。若我已取得證書資格，請協助下載 PDF，並回報檔名與儲存位置；尚未符合時請說明缺少項目。

CHOOSE THE RIGHT CONNECTION

兩種主要方式與外掛橋接比較

比較項目Codex 內建瀏覽器目前 Chrome＋DevTools MCPChrome 外掛＋橋接
連線方式在 Codex 內建瀏覽器開啟課程網址。MCP 透過遠端偵錯連到目前 Chrome 分頁。外掛需搭配能提供 MCP 的本機服務或 Native Messaging host。
登入工作階段通常是內建瀏覽器自己的工作階段，需要時在該處登入。沿用已登入 Chrome 的頁面工作階段；由本人完成登入。依外掛和橋接設計，不能假設會共用現有登入狀態。
是否需要外掛依內建瀏覽器功能而定，通常不需 Chrome 外掛。本次連線不需要額外安裝外掛；遠端偵錯已啟用。需要特定外掛、權限與橋接設定；單裝一般外掛不會自動變成 MCP。
適合情境快速開頁、查看教材或使用獨立瀏覽器工作階段。希望助手查看已登入 Chrome 中的頁面、畫面或影片狀態。需要特定頁面功能或自行整合自動化工具時。
操作前確認核對網址、標題與目前登入帳號。只連接信任的 MCP；遠端偵錯可能讀寫瀏覽器資料。先檢查外掛來源、要求權限與本機橋接程式。
共同原則登入、驗證與課程學習由學員本人完成。MCP 是工具連線方式，不代表平台授權或完課保證。

若你只需要本次課程的頁面檢查與協助，先用已能連線的方式即可。外掛是可選路徑，安裝前需確認具體名稱與權限。

TROUBLESHOOTING

卡關時先檢查什麼？

使用內建瀏覽器時看不到 Chrome 的登入狀態？

內建瀏覽器可能使用獨立工作階段。請在實際使用的瀏覽器本人登入私人 Gmail，再請 Codex 重新讀取該頁；不要在聊天中貼出憑證。

使用目前 Chrome MCP 一定要安裝外掛嗎？

本次 MCP 使用 Chrome 遠端偵錯連線，沒有安裝 Chrome 外掛。外掛是另一種做法；它需要合適的 MCP 或本機橋接程式，並應先檢查權限。

Codex 可以只靠畫面完整看完影片嗎？

不一定。可讀取截圖或播放時間，不代表取得了整段旁白或逐字稿。若播放器沒有字幕軌，請提供字幕、逐字稿或教材，才能整理完整影片內容。

遠端偵錯看起來已開啟，還要做什麼？

只確認 MCP 連到你預期的 Chrome。這項設定讓可信任的連線有機會控制瀏覽器並讀取網站資料；不要讓不認識的程式連線。

Codex 說看不到我的課程分頁？

內建瀏覽器請在該工作階段登入；使用目前 Chrome MCP 時，確認遠端偵錯已啟用並重新指定正確分頁。必要時重新整理頁面或開始新的 Codex 對話。

播放器一直轉圈或白畫面？

先回報「尚未開始播放」，等待載入並確認網路。可依平台操作重新進入單元；不應把白畫面當成已學習，也不要直接跳過尚未觀看的內容。

出現「禁止多重視窗」或登入過期？

停止切換、閱讀訊息，關閉多餘課程播放器，保留一個學習視窗；若要求重新登入，由學員處理，再確認實際進度。

可以一直在背景自動播放到完課嗎？

不要把本頁指令當成持續監控或背景排程。是否仍在執行，要以對話中的實際任務狀態為準；學員仍需觀看並確認平台紀錄。

可以幫我整理影片重點嗎？

可以請 Codex 根據可取得的字幕、逐字稿或教材整理重點；如果拿不到內容，應提供教材或文字，不能把只看見播放器畫面當成完整理解整部影片。

沒有證書下載按鈕？

先查看閱讀時間、測驗、問卷等完成條件及平台紀錄，確認課程是否提供證書。不能假設每門課都有 PDF 證書。
