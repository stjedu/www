START WITH A REAL PAGE

先做一段，確認接力可行

這份流程以本次桌面環境的臺北 e 大操作經驗為例：讀取課程 → 開啟單元 → 確認播放 → 等待結束 → 切換下一段。其他平台的播放器、完成條件與下載方式可能不同，應先讀取現場畫面。

本次已實測

臺北 e 大的課程頁讀取、前言播放、字幕更新與下一單元切換。這些經驗不代表所有課程或帳號均可採用相同流程。

準備好再開始

桌面 Codex 對話、已連接的 Chrome、研習課程網址，以及可自行完成登入驗證的學員。

01

環境準備

使用能連接瀏覽器的桌面環境。

  1. 開啟桌面程式中的 Codex 對話。確認目前版本、帳號與工作區提供瀏覽器操作功能。
  2. 依官方設定流程，在設定的 Computer Use／電腦使用 中選擇 Chrome，依提示安裝所需外掛與瀏覽器擴充功能。
  3. 回到設定確認瀏覽器可管理；在對話輸入 @，選取 Chrome 或指定課程分頁。使用安裝擴充功能的同一個 Chrome 個人資料。
貼給 Codex 的指令

請先檢查你是否能連接我的 Chrome。列出目前可用的瀏覽器，暫時不要操作課程。

02

確認網站連線

先測試讀取，再進入正式學習。

  1. 在 Chrome 開啟研習平台，只保留需要的課程視窗。
  2. 請 Codex 讀取目前頁面標題，回報平台名稱與可見的操作按鈕。
  3. 若出現網站存取提示，先確認網址與用途，再依本次任務授權。功能名稱與可用性會隨版本及工作區設定不同。
貼給 Codex 的指令

@Chrome 請查看我開啟的研習網頁，先回報平台名稱、頁面標題與目前狀態，不要報名或提交資料。

03

登入與選課接力

帳號驗證由學員完成。

  1. 自行完成登入、憑證、驗證碼與平台要求的驗證。密碼不需要貼到聊天。
  2. 自行挑選並報名課程，再開啟課程頁面。
  3. 回到 Codex，說明已登入、課程名稱與希望協助的範圍；若 Codex 尚未看得到新頁面，重新指定該分頁。
貼給 Codex 的指令

我已登入並報名，課程是【填入課程名稱】。請接手檢查這個課程的單元清單與完成條件，先不要切到測驗。

04

開啟並確認播放

要確認真的開始播放，不能只確認點過按鈕。

  1. 請 Codex 開啟第一個單元，等待播放器載入。
  2. 如有播放按鈕，協助點擊；若瀏覽器要求本人互動，依提示點一下播放。
  3. 確認畫面、字幕或播放時間有前進，再開始觀看。轉圈或白畫面表示尚未確認播放成功。
貼給 Codex 的指令

請開啟第一單元並協助播放。保留正常速度，確認畫面、字幕或播放時間有更新，再告訴我是否已開始。

05

觀看與單元切換

由你學習，Codex 協助控制小按鈕。

  1. 你實際觀看課程。需要時請 Codex 暫停、繼續，或解釋可取得的字幕與教材。
  2. 這一段播完後，請 Codex 先確認結束畫面或時間，再切下一段並驗證播放。
  3. 對話回覆結束不等於背景持續監控。若沒有持續執行中的任務，請在段落結束時再傳訊息。
貼給 Codex 的指令

這一段播完了。請先確認是否已到結尾，再按下一段；確認新影片開始播放後回報單元名稱。

06

測驗、紀錄與證書

依平台的實際結果完成驗收。

  1. 遇到計入完課資格的測驗，由學員理解題目並作答。Codex 可解釋教材觀念；不要把代考當成操作流程。
  2. 問卷依學員的實際體驗填寫。離開播放器時，優先使用平台的正式離開按鈕，再查看學習紀錄。
  3. 平台確認符合資格且提供證書後，再請 Codex 協助下載並回報實際檔名與位置。不要直接改寫時數或完成狀態。
貼給 Codex 的指令

請查看平台實際顯示的完課條件與學習紀錄。若我已取得證書資格，請協助下載 PDF，並回報檔名與儲存位置；尚未符合時請說明缺少項目。

CHOOSE THE RIGHT CONNECTION

Codex 版與自訂 MCP 有何不同？

比較項目本頁 Codex 瀏覽器協作自訂 Chrome DevTools MCP
連接方式依桌面環境設定 Chrome 擴充功能，再在對話指定瀏覽器或分頁。另外安裝並設定 MCP 伺服器，需符合所選工具的環境需求。
操作入口自然語言指令，先確認可見頁面再操作。由代理人呼叫伺服器提供的工具；工具名稱依實作而異。
教師起步適合先練習一段影片的登入接力與播放確認。適合已有技術支援、需要特定工具整合的環境。
共同原則依平台規則協助操作、由學員實際學習；不要混用不同工具的指令名稱。

MCP 是工具整合方式，不等於研習平台授權，也不是完課保證。已能連接瀏覽器時，可先完成基本協作測試，再評估是否需要自訂 MCP。

TROUBLESHOOTING

卡關時先檢查什麼？

Codex 說看不到我的課程分頁？

確認 Chrome 使用安裝擴充功能的同一個個人資料，並在對話重新指定瀏覽器或分頁。檢查該網站存取權限；必要時重新啟動瀏覽器或開始新的 Codex 對話。

播放器一直轉圈或白畫面？

先回報「尚未開始播放」，等待載入並確認網路。可依平台操作重新進入單元；不應把白畫面當成已學習，也不要直接跳過尚未觀看的內容。

出現「禁止多重視窗」或登入過期？

停止切換、閱讀訊息，關閉多餘課程播放器，保留一個學習視窗；若要求重新登入，由學員處理，再確認實際進度。

可以一直在背景自動播放到完課嗎？

不要把本頁指令當成持續監控或背景排程。是否仍在執行，要以對話中的實際任務狀態為準；學員仍需觀看並確認平台紀錄。

可以幫我整理影片重點嗎？

可以請 Codex 根據可取得的字幕、逐字稿或教材整理重點；如果拿不到內容，應提供教材或文字，不能把只看見播放器畫面當成完整理解整部影片。

沒有證書下載按鈕？

先查看閱讀時間、測驗、問卷等完成條件及平台紀錄，確認課程是否提供證書。不能假設每門課都有 PDF 證書。
