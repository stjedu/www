GitHub 個人網頁｜教師研習教材包

1. 播放 MP4 即可看到中文字幕並聽到中文旁白。
2. 解壓縮整個資料夾後，也可雙擊「開啟教學影片.html」，使用章節跳轉播放。
3. index.html 是給學員使用的首頁範本；用記事本或文字編輯器開啟並複製完整原始碼。
4. 「教學講稿與章節.md」含完整逐字講稿、時間點與官方資料來源。
5. SRT 是可另行編輯或上傳 YouTube 的繁體中文字幕。影片已有燒入字幕，平常播放不必再開字幕軌，以免重複顯示。

建議：播放約 8 分半的影片，搭配 30～45 分鐘分段實作。
教學畫面採實際 GitHub 截圖加上圖解與標示，不是連續操作實錄。
請把示範帳號 stjedu 換成自己的使用者名稱。
