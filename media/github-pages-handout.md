# GitHub 個人網頁｜教師研習教學影片

2026-11-05 製作。16:9，1920×1080，台灣中文女聲，語速 -5%。繁體中文字幕已燒入影片，另附可編輯 SRT。畫面採實際 GitHub 截圖與逐步圖解，不是連續操作實錄。

## 使用方式

先下載 index.html 作為首頁範本。影片中的 stjedu 為示範帳號，請換成自己的帳號；既有 www 儲存庫截圖只用來示範按鈕位置。老師應在自己新建的「帳號.github.io」儲存庫操作。

## 章節與逐字講稿

### 00:00:00　建立自己的 GitHub 教學網頁

各位老師好，這堂課要帶大家，用瀏覽器建立自己的 GitHub 個人教學網頁。我們會從儲存庫命名開始，放入首頁，再啟用網站發布。影片採用實際介面截圖，加上重點標示。看到暫停提示時，可以先完成操作，再繼續觀看。

### 00:00:25　01　先認識今天的成果

今天的成果，是一個包含老師介紹、課程教材和學習資源的教學小站。老師會拿到一份名為 index.html 的首頁範本，不必先學會所有程式碼。先完成第一個網站，之後再慢慢換成自己的內容。

### 00:00:46　02　準備帳號與首頁範本

請先登入 GitHub，並完成帳號需要的驗證。如果還沒有帳號，請先完成註冊，再回到這個步驟。請記下 GitHub 的使用者名稱，注意，它不是 Gmail 信箱，也不一定等於畫面上的中文姓名。接著準備本課程附上的首頁範本。

### 00:01:10　03　分清楚兩種網站網址

GitHub Pages 常見有兩種網址。個人網站使用，帳號點 github 點 io。專案網站則會在後面，多一段專案名稱。像先前的研習教材網站，網址後面有 www，就是專案網站。今天要建立個人網站，所以儲存庫名稱要符合自己的帳號。

### 00:01:37　04　進入新增儲存庫頁面

在 GitHub 右上角，點加號，選擇 New repository，也可以直接開啟畫面上的新增網址。儲存庫可以想成網站的檔案資料夾，同時保存修改紀錄。先看 Owner 欄位，確認是自己的帳號。示範畫面使用 stjedu，老師請換成自己的使用者名稱。

### 00:02:02　05　輸入正確的儲存庫名稱

在 Repository name 欄位，輸入自己的帳號，再接上點 github 點 io。例如 Owner 是 stjedu，名稱就是畫面上的這一串。請用小寫字母，仔細核對拼字。如果名稱已經存在，先到自己的儲存庫清單找看看，不要另外加數字，否則會變成另一個專案。

### 00:02:28　06　選擇 Public 並建立

使用免費帳號做這次練習，請選擇 Public，也就是公開儲存庫。把 Add README 切換為開啟，讓儲存庫先有初始內容。其他選項先保留預設，再點最下方的 Create repository。現在可以暫停影片，確認自己的儲存庫已經建立成功。

### 00:02:53　07　新增首頁 index.html

接下來，在剛建立的個人網站儲存庫中，開啟 Code 頁籤，選擇 Add file，再選 Create new file。檔名輸入 index.html，全部使用小寫，並放在最外層。這裡借用既有的 www 儲存庫示範按鈕位置，老師實作時，請留在自己的個人網站儲存庫。

### 00:03:19　08　貼上完整首頁範本

請用記事本或文字編輯器，開啟課程附的 index.html。全選檔案內容，複製後，貼到 GitHub 的編輯區。要貼上完整程式碼，從最前面的文件宣告，到最後的結束標籤。不要只複製瀏覽器裡看得到的網頁文字。

### 00:03:42　09　換成自己的教學內容

現在先做三個簡單修改。把王老師改成自己的稱呼，補上任教科目，再替換一個教材連結。修改文字時，先保留前後的標籤。修改連結時，換掉 href 引號裡的網址。網站會公開，請使用適合公開分享的教材，不要放學生個資或密碼。

### 00:04:10　10　提交變更，真正儲存

編輯完成後，先點右上角的 Commit changes。彈出視窗後，輸入修改說明，例如，建立我的教學首頁。確認是直接提交到 main 分支，再按視窗裡的 Commit changes。這一步才是真正儲存。只把內容貼進編輯器，還不算完成。

### 00:04:34　11　確認首頁已經存在

提交後，回到 Code 的檔案清單，確認最外層出現 index.html。點進檔案，檢查內容是不是剛才貼上的範本。如果使用上傳檔案的方式，也要檢查副檔名，避免變成 index.html.txt。請暫停確認這個檢查點，再進行網站發布。

### 00:05:00　12　開啟 Settings → Pages

現在開啟儲存庫上方的 Settings，再從左側選單找到 Pages。注意，這是這個儲存庫的設定，不是右上角頭像裡的個人設定。進入後，找到 Build and deployment，也就是建置與部署區塊。接下來要告訴 GitHub，從哪裡發布網站。

### 00:05:23　13　設定網站的發布來源

在 Source 下拉選單中，選擇 Deploy from a branch。Branch 選 main，旁邊的資料夾選斜線 root，表示儲存庫的最外層。這組設定，要和剛才 index.html 的位置一致。如果選成 docs 資料夾，最外層的首頁就不會是這次發布的來源。

### 00:05:47　14　按 Save，等待部署完成

確認來源後，點 Save。第一次發布通常要等待一段時間，官方說明提醒，更新可能需要十分鐘。可以到 Actions 查看建置與部署進度。畫面是已發布網站，所以 Save 呈灰色；老師第一次設定選項後，就能儲存。等待時，不需要反覆修改設定。

### 00:06:14　15　開啟你的個人網站

部署成功後，回到 Pages，找到網站網址或 Visit site 按鈕。個人網站的網址，是自己的帳號點 github 點 io，後面不需要加 www。請檢查首頁標題是否正確，教材連結能不能開啟，再用手機看看版面。完成這三項，就能把網址分享給學生。

### 00:06:41　16　之後如何修改與更新？

之後要更新教材，回到 Code，點開 index.html，再點鉛筆圖示進行編輯。修改完成，同樣要提交變更。等待部署後，重新整理網站就會看到新版。如果還是舊內容，可以按住 Control，再按 F5 強制重新整理，或使用無痕視窗檢查。

### 00:07:08　17　遇到 404，先檢查這四項

如果看到四零四，先依序檢查四件事。儲存庫名稱，是否和自己的帳號一致。main 分支最外層，有沒有 index.html。Pages 的來源，是否選 main 和 root。最後，確認部署已完成，並且開的是網站網址，而不是 GitHub 儲存庫的網址。

### 00:07:34　18　課堂驗收：分享你的成果

最後請完成三項驗收。打開自己的個人網站，確認有自己的稱呼、科目，以及一個能使用的教材連結。再改一段文字，提交後，確認網站成功更新。請把網址分享給旁邊的老師，互相點開測試。恭喜，您已經完成第一個可以持續經營的教學小站。

### 00:08:02　課後資源與操作速記

課程附上首頁範本、中文字幕和逐字講稿，方便老師課後練習。操作順序記住五個重點，正確命名、放入首頁、提交儲存、啟用 Pages，最後開啟網站驗收。介面可能隨時間調整，若按鈕位置不同，可以對照 GitHub Pages 的官方說明。謝謝各位老師。
